# Agentic Workflow Execution

## Definition
Applies when the AI system can trigger actions, use tools, or execute workflow steps.

## Control emphasis
- delegated identity
- action scope minimization
- tool allowlisting
- rollback and kill switch capability
- action-level audit trail
- memory and context integrity (what the agent stores, who can write to it, how it is cleared)
- trust between agents (authentication of agent-to-agent messages and delegated tasks)
- inventory of agents, the tools they can call, and the MCP servers they use
